## 模組 1：產品負責人提供的流程草圖（2026-11-14）

- **輸入**：Raw CTI 報告、STIX 1.x、STIX 2.x
- **STIX Parser**：確認 XML 格式、把缺的欄位標成 NULL
- **LLM 分析六大類資訊**：事件基礎資訊、攻擊行為（TTPs）、Relationships、
  Target Context（如 OS、服務版本）、Artifacts（如工具、IOC、指令）、Evidence / Refs
- **防止幻覺**：要求標記段落與引用、無法取得的資訊要標記、evidence 驗證
- **Schema Validator**：把 LLM 結果填入、驗證 JSON 有效
- **輸出**：缺少項目、生成品質評估、JSON
