# CISA AA22-320A source retrieval

## Summary

- A direct server-side fetch (`curl`/`httpx`, including a browser `User-Agent`) is
  **blocked by CISA with HTTP 403** from this host — their Akamai WAF rejects
  non-browser clients on TLS/IP/challenge grounds, not just the UA. The Codex worker
  saw the same 403. We did **not** attempt to defeat the WAF.
- The platform **WebFetch** tool retrieved the files successfully. It saved the PDF's
  **raw bytes** to disk; those bytes are the genuine advisory (SHA-256 verified below).
