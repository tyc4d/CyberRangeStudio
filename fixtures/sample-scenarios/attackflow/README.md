# Attack Flow fixtures

- `cisa-iranian-apt.afb` is the unmodified CISA Iranian APT sample from the official Attack Flow corpus. The corpus currently serves this sample in the `.afb` editor format rather than as a STIX `.json` bundle.
- `official-attack-flow-example.json` is the official STIX 2.1 example from the same repository's `stix/` directory. It includes attack-flow, action, condition, operator, and asset objects and is used for import/export round-trip tests.

Sources:

- https://raw.githubusercontent.com/center-for-threat-informed-defense/attack-flow/main/corpus/CISA%20Iranian%20APT.afb
- https://raw.githubusercontent.com/center-for-threat-informed-defense/attack-flow/main/stix/attack-flow-example.json
