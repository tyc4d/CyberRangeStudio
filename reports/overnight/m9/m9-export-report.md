# m9-export report

Branch `agent/m9-export`. Owned files only: `apps/api/app/poc/export/{__init__,bundle,test_export}.py`.

## What it does
`app.poc.export.export(scenario_id) -> {bundle_path, manifest}` writes a ZIP to
`DATA_DIR/exports/<id>/<id>-v<ir_version>-<UTCstamp>.zip` (new file every time, never overwrites; written
`.partial` then `os.replace`) and records it with `poc_store.save_export`.
`build_bundle()` returns bytes+manifest without writing; `verify_bundle(path|bytes)` re-checks a bundle.

Layout: README.md, manifest.json, scenario/{scenario.json,scenario.yaml,attack-chain.json},
infrastructure/{docker-compose.yml,iac-report.json,.env.example,templates/demo-app/* (only if compose builds it)},
validation/{validation-plan.json,poc-manifest.json,results.json,fidelity-report.json}, evidence/evidence-index.json.

Only real artifacts:
- IR from `store.get` (secret-redacted). attack-chain = IR actions+relations(+flow), labelled as description, not result.
- Compose via `generator.get_generated` (on-disk file, verified current vs plan). Missing → blocking entry;
  stale → blocking entry, stale file NOT exported. Only change: demo-app build context path relocated into the
  bundle (recorded in `generated_by` + README).
- Validation files only if the poc tables have rows; fidelity only if `service.report()` returns one
  (today: NotImplementedError → omitted, noted in README). Nothing fabricated.
- Evidence: index only (raw not copied); sha256 re-verified for files inside DATA_DIR; paths outside DATA_DIR
  are never read.
- Terraform/Ansible: never generated by this project → omitted, listed (non-blocking, see requests note §3).

rebuildable=false when: no compose / stale compose / no valid env plan / any VM host (VM image) / any
not_deployed or unresolvable host image / build context missing.

Secrets: secret-named keys → `[REDACTED]` (whole subtree), inline `password=...` values, PEM keys, AKIA, gh*_,
sk-, JWT, Bearer, PVEAPIToken, and literal values of secret-named env vars (len≥8) are redacted. Final scan of
every file; any hit → `ExportError` (fail closed, nothing written). `.env.example` = placeholders only.
Manifest validated against `ExportManifest` schema before writing.

## Tests (real, run)
`PYTHONPATH=apps/api:packages/contracts python -m pytest apps/api/app/poc/export -q` → **13 passed**.
`apps/api/app/poc apps/api/app/iac` together → 57 passed.
Compose in tests is the REAL `compose_document()`/`inspect_plan()` output for the generator's own fixture plans;
only the disk lookup and stores are redirected to a temp dir. Covers: layout, per-file sha256 verify, tamper
detection, no secret values (IR password, inline password, AWS key, env token), missing images listed
(not_deployed host, VM host), terraform/ansible omitted, absent validation omitted, secret in compose aborts,
two exports → two files + two DB rows, demo plan rebuildable with bundled build context.
