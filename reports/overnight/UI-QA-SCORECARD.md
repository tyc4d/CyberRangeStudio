# 講師部署與連線資訊 UI 專項評分表

本表只評部署管理與講師連線資訊畫面，不代表產品整體 QA 驗收。目標為 70/100；正式整體門檻仍依 `QA-SCORES.md`，且不得用本表取代。

## 執行方式

- 使用既有情境和目前實際 API 回應；只讀瀏覽器操作，只允許 GET。
- 不使用固定 API 回應、模擬部署狀態、部署/清除情境、啟動服務或攻擊探針作為評分證據。
- 分別檢查繁體中文與英文、桌面 1440px 與手機 390px。
- 測試者不先讀操作說明，依任務自行找出答案並保留可重現步驟。
- 如沒有已確認可達的講師入口，正確顯示「目前沒有入口」可以得分；不得因基礎設施未提供入口而要求 UI 編造位址。

## 任務

以既有情境打開部署管理頁，回答：

1. 講師現在可從哪個入口連入？若沒有，畫面是否清楚說明。
2. 哪些位址只是平台主機或靶場內使用？列出主機、服務、協定、埠號及允許的主機間連線。
3. 伺服器預計及實際放在哪一層／位置？哪些資訊尚未提供？
4. 若沒有講師入口，下一步要找誰或補什麼資料？

## 評分上限

- 若畫面把未驗證、平台本機或靶場內位址標成講師可連，或顯示猜測的 IP/網址/帳密，本輪判定不合格，總分最高 49。
- 任一評分者若未使用真實 API 回應或有非 GET 請求，本次結果不列入分數。
- 70 分只表示本 UI 專項達到最低展示門檻，不代表部署、外部連線、PVE 或整體產品驗收完成。
